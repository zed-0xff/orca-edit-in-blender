# Changelog

## 0.1.0

- Docked **Edit in Blender** panel with an auto-refreshing object list.
- **Edit selected** exports the checked objects to STL and opens them in Blender;
  later exports are sent to the Blender window the plugin started instead of launching a new one.
- Saving in Blender (Ctrl+S) writes the edited meshes back; **Load edits** opens them in OrcaSlicer as new objects.
- Compact layout, remembered panel width, optional auto-open at startup, all stored in the plugin config.
